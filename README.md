## 📌 Visão Geral

O **Jogo do Número Secreto** é uma aplicação web leve e interativa onde o jogador deve adivinhar um número gerado aleatoriamente pelo sistema.

Desenvolvido utilizando apenas tecnologias front-end, este projeto tem como foco o desenvolvimento de **lógica de programação**, **manipulação do DOM** e **interação com o usuário**.

---

## 🎮 Como Jogar

- O sistema gera um número secreto aleatório  
- O jogador insere um palpite  
- O jogo responde informando se o número é:
  - 🔼 *Maior*
  - 🔽 *Menor*
  - ✅ *Correto*  
- O jogo continua até o jogador acertar
